# MENU proyecto final

Implementación del algoritmo **Stable Fluids** con Taichi.


## Estructura del proyecto

| Archivo | Descripción |
|---|---|
| `etapa1.py` | Etapa 1: Densidad - difusión |
| `etapa2.py` | Etapa 2: Densidad - advección |
| `etapa3.py` | Etapa 3: Velocidad - añadir fuerzas |
| `etapa4.py` | Etapa 4: Velocidad - difusión y advección. |
| `etapa5.py` | Etapa 5:Proyección para incompresibilidad |

---

## Cómo ejecutar

Cada etapa es un script independiente, por tanto, simplemente ejecutar el script que se quiera probar. Para añadir densidad utilizar el click derecho, y para añadir fuerzas, el click izquierdo.
